## 2026

### Week 4 — PeachSanitize (Jun 7, 2026)

**Type:** Tool (PowerShell module, PSGallery)

**Description:** Sanitize sensitive data from JSON payloads before pasting into AI tools. Detects API keys, tokens, emails, IP addresses, phone numbers, SSNs, credit card numbers, and credentials using regex patterns, Shannon entropy, and key-name heuristics. Runs entirely locally — no network calls.

**Install:** `Install-Module PeachSanitize`

**Repository:** https://github.com/Peach-Security/PeachSanitize
